## 📌 Sobre o Projeto

O **Lista de Tarefas** é um projeto simples e funcional desenvolvido em **HTML, CSS e JavaScript**, que permite ao usuário:

* ➕ Adicionar novas tarefas
* ✅ Marcar tarefas concluídas
* ❌ Excluir tarefas indesejadas
* 🔍 Pesquisar rapidamente uma tarefa específica
* 🗂️ Filtrar por status (Todos, Concluídos ou Pendentes)

Foi meu **primeiro projeto prático (2023)**, criado para aplicar conceitos de desenvolvimento web e manipulação do DOM.

👉 [Acesse o projeto online aqui](https://leonardomartinsb.github.io/Projeto-Lista-de-Tarefas-2023/)

---

## 🚀 Tecnologias Utilizadas

* **HTML5** – estrutura da aplicação
* **CSS3** – estilização responsiva e moderna
* **JavaScript (ES6+)** – lógica e manipulação de tarefas
